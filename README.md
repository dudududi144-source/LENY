# 🌟 LENY — העולם של לני

**משחק היברידי לילדים: פלטפורמות × למידה** — כל שער במשחק נפתח רק באמצעות פתרון חידה חינוכית, והידע עצמו הופך לכוח במשחק (מגן, מגנט, כוכב).

> איחוד של שני משחקים: *"לני — ההרפתקה הניאונית"* (פלטפורמות ארקייד) ו*"לני הגיבורה"* (למידה לגיל הרך) למשחק אחד עם ארכיטקטורה מודולרית.

### מכניקות מפתח
- **שערי חוכמה** — נגיעה בשער פותחת חידה; פתרון נכון פותח את הדרך **ומעניק כוח** (Power-Learning)
- **בוס חכם** — כל מכה על הגנרל דורשת מענה נכון על חידה
- **קושי מסתגל** — המשחק מזהה קושי (בחידות או בפלטפורמות) ומרכך אוטומטית את הצד השני
- **3 רמות קושי** + פינת הורים מוגנת בהחזקה (שם הילדה, צלילים, מצב לילה, איפוס)
- **TTS עברי** — הקראת הוראות, שמות חיות ומילות עידוד
- **אודיו סינתטי מלא** — מוזיקה, אפקטים וצלילי חיות/כלים ב-WebAudio (ללא קבצים חיצוניים)
- **דמות לני** — SVG מונפש עם אביזרים שנאספים, אנימציות (גל, ריקוד, סיבוב, עידוד)
- **מדבקות** 📔 — מסך אלבום שמציג פרסים שנאספו וכוכבי חוכמה
