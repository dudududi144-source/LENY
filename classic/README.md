# classic/ — הגרסאות המקוריות

תיקייה זו משמרת את משחקי המקור שאוחדו לתוך **LENY**:

| קובץ | תיאור |
|------|--------|
| `lenny-heroine.html` | **לני הגיבורה** — משחק חינוכי לגיל הרך (5 עולמות למידה, פרסים, אלבום, מדבקות, פינת הורים, TTS). המקור לדמות ה-SVG, צלילי החיות/כלים, מסך המדבקות, מצב הלילה ופינת ההורים |

> כל קובץ הוא משחק עצמאי לחלוטין — אפשר לפתוח ישירות בדפדפן (או לשרת עם `python3 -m http.server`).
> הקוד כאן נשמר כפי שהיה, לצורכי עיון והשוואה; הפיתוח הפעיל מתרחש בשורש הפרויקט (הגרסה המודולרית).
