## צ'קליסט לכל מכשיר
- [ ] המשחק נטען תוך <5 שניות
- [ ] ≥50fps בריצה עם פיצוצי חלקיקים
- [ ] כפתורי מגע (◀ ▶ ⤒) ממוקמים מעל אזור האחיזה
- [ ] אין גלישת טקסט בעברית (RTL) באף מסך
- [ ] התמדה שורדת רענון + סגירת דפדפן
- [ ] מצב טיסה אחרי ביקור ראשון: המשחק עובד (PWA)
- [ ] צלילים לא חורגים מעוצמה סבירה
- [ ] הקראה (TTS) עובדת או נופלת בשקט (בלי קריסה)
