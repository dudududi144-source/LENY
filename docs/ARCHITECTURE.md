# 🏗️ LENY — מסמך ארכיטקטורה

> גרסה 2.0 · ארכיטקטורת מודולים (ES Modules) ללא כלי בנייה · מתוכננת לגדילה, בדיקות ותחזוקה

---

## 1. עקרונות מנחים

1. **הפרדה מלאה בין שכבות** — נתונים / מנוע / רינדור / ממשק / אודיו, ללא תלות מעגלית
2. **מצב מרכזי אחד** (`state.js` להתמדה, `runtime.js` לריצה) — מקור אמת יחיד
3. **תקשורת عبر אפיק אירועים** (`bus.js`) — המנוע אינו יודע על המסכים, והמסכים אינם יודעים על המנוע
4. **אפס תלויות חיצוניות בזמן ריצה** — כל האודיו, הגרפיקה והאנימציה נוצרים בקוד (Canvas/SVG/CSS)
5. **עברית-ראשית, RTL מלא, נגישות** — `prefers-reduced-motion`, aria, פונטים עם ניקוד (Heebo)

## 4. חוזה אירועים (Event Bus)

| אירוע | מופץ ע"י | נתונים | מטרה |
|-------|----------|--------|------|
| `level-done` | engine | `{first:boolean}` | מסך סיום + הענקת פרס |
| `game-over` | engine | — | מסך הפסד + עדכון שיא |
| `win` | engine | — | חגיגת ניצחון + קונפטי |

זרימה לדוגמה (סיום שלב):
```
player → flag collision
  → engine.levelDone()
      → עדכון S (items/stars/best) + save()
      → bus.emit('level-done', {first})
  → scenes.onLevelDone()
      → showScreen('done') + אנימציית לני + קונפטי (אם פרס חדש)
```

## 5. סכמת מצב

### 5.1 התמדה (`localStorage`, מפתח `leny-world-v1`)
```json
{
  "items": [0, 2],
  "gates": { "1:2": true },
  "stars": { "0": 3 },
  "sound": true,
  "night": false,
  "diff": "רגיל",
  "name": "",
  "best": 4200
}
```
- `items` — אינדקסי עולמות שהושלמו (פרסים שנאספו)
- `gates` — שערים פתוחים, מפתח `"עולם:מספר"`
- `stars` — כוכבי חוכמה (חידות שנפתרו) לכל עולם 0–3
- **עמידות:** טעינה דרך `Object.assign(defState(), saved)` — גרסאות ישנות/שבורות נופלות לברירת מחדל בבטחה

### 5.2 מצב ריצה (`RT`)
```
RT = {
  screen: 'title|hub|play|done|over|win|stickers',
  paused, puzzleBusy,          // בקרת זרימה
  level, score, coins, lives,  // התקדמות בשלב
  theme, player, cam,          // עולם נוכחי
  ents[], parts[], texts[],    // ישויות, חלקיקים, טקסטים צפים
  levelMap[][], cols, rows,    // מפת אריחים
  boss, gates[],               // בוס + שערים
  powers{shield,magnet,star},  // כוחות פעילים
  combo, comboT, skill,        // קומבו + קושי מסתגל
  shake, time, invuln, dying, hintTimer, curHint
}
```

## 6. מנוע פיזיקה

| קבוע | ערך | משמעות |
|------|-----|--------|
| `GRAV` | 0.62 | תאוצת כבידה (פיקסל/פריים²) |
| `JUMP` | -12.6 | מהירות קפיצה ראשונה (~2.9 אריחים) |
| קפיצה כפולה | `JUMP×0.92` | ~2.5 אריחים נוספים |
| `MAXV` | 5.2 | מהירות אופקית מרבית (×1.35 בכוכב) |
| `MOVE` / `FRIC` | 0.9 / 0.78 | תאוצה וחיכוך |
| `TILE` | 44 | גודל אריח |

- **התנגשויות:** ציר-מופרד (X ואז Y) מול מפת אריחים; `solidAt` בשתי נקודות לכל ציר
- **שערים סגורים:** מוצקים לכל גובה העמודה (`gateClosedCol`) — אי אפשר לעקוף בקפיצה
- **קפיצת שוליים:** `coyote=8` + `jbuf=8` (input buffering) לתחושה מדויקת
- **בוס:** פיזיקה זהה לשחקן + קפיצה לעבר השחקן; כל מכה דורשת מענה על חידה

## 7. מערכת חידות

| עולם | סוג חידה | מכניקה |
|------|----------|--------|
| 1 | חיות | הקשבה לצליל מסונתז → בחירת החיה |
| 2 | צורות | זיהוי צורה זהה (2 סבבים) |
| 3 | אותיות | אות פותחת של מילה (ניקוד מלא) |
| 4 | מוזיקה | חזרה על מקצב (Simon) |
| 5 | רגשות | התאמת סיטואציה → רגש |
| בוס | מעורב | חידה אקראית קצרה בכל מכה |

**עקרונות פדגוגיים:**
- אין "הפסד" בחידה — טעויות מניבות עידוד + רמז לאחר `DIFF.hint` טעויות
- כל חידה מוקראת ב-TTS ומלווה בצליל
- מספר האפשרויות נגזר מרמת הקושי (2/3/4)

## 8. מודל קושי מסתגל (`skill`)

```
skill ∈ [0.7, 1.15]   (מתחיל ב-1)

ירידה: -0.05 בכל פגיעה בשחקן או טעות בחידה
עלייה: +0.03 בכל פתרון חידה

השפעות:
  • מהירות אויבים ובוס × skill
  • רמת קושי נבחרת (קל/רגיל/מאתגר) מכפילה:
      מהירות ×0.7/×1/×1.25 · אופציות 2/3/4 · חיים 4/3/3 · סף רמז 1/2/3
```

## 9. אודיו

- **שני ערוצי רווח:** מוזיקה (`0.16`) ואפקטים (`0.85`) תחת `master` אחד
- **מוזיקה:** ארפג'ים מתוזמנים — סולם מז'ורי ביום, מינורי בלילה
- **צלילי חיות:** סינתזה מלאה (כלב: sawtooth+lowpass; חתול: bandpass sweep; פרה: 140→90Hz; חזיר; ציפור)
- **נעילת דפדפן:** `AudioContext` נוצר רק אחרי אינטראקציה ראשונה (`pointerdown`)

## 10. נגישות וביצועים

- `prefers-reduced-motion` — ביטול אנימציות
- `aria-*` ותוויות בעברית; `role="status"` בטוסטים
- רינדור: רק אריחים/ישויות בטווח המצלמה (culling)
- `devicePixelRatio` עד 2×; קנבס 960×540 לוגי (16:9) עם מכתם (letterbox)
