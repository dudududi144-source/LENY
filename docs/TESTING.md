## בדיקות קצה-לקצה (E2E · Playwright)
**מטרה:** בדיקת המשחק כמוצר שלם מול דפדפן אמיתי — לא רק יחידות קוד.

### הרצה מקומית
    npm install
    npx playwright install chromium
    npm run test:e2e

### תרחישים מכוסים (e2e/game.spec.js)
1. טעינה ללא שגיאות קונסול + חלון שגיאות ריק
2. פתיח → רכזת עם 10 עולמות
3. רכזת → כניסה לעולם 1 → קנבס פעיל
4. גינת יצירה: מדבקה נשמרת בין טעינות (התמדה אמיתית)

### מדיניות
- כל פיצ'ר חדש עם זרימת משתמש — חייב תרחיש E2E
- ה-E2E רץ בוורקפלואו נפרד (e2e.yml) כדי לא להאט את המשוב המהיר
