# 🎯 GDD — מסמך עיצוב משחק (Game Design Document)

## 1. חזון
משחק אחד לילדים בגילאי 4–10 שבו **משחק ולמידה הם אותו דבר**: כל התקדמות פיזית דורשת ידע, וכל ידע מתורגם מיד לכוח פיזי בעולם.

## 2. עמודי תווך (Pillars)
1. **כיף קודם** — שליטה הדוקה (coyote time, jump buffering), משוב מיידי בכל פעולה
2. **למידה סמויה** — אין "מבחנים"; חידות הן שערים, מפתחות ומכות-בוס
3. **עידוד תמידי** — אין כישלון מעניש: רמזים, עידוד קולי, קונפטי על כל ניצחון
4. **בטוח לילדים** — ללא פרסומות, ללא רכישות, פינת הורים מוגנת, אפס מעקב

## 3. לולאת משחק (Core Loop)
1. בחירת עולם ברכז (Hub)
2. ריצה/קפיצה/איסוף יהלומים בשלב פלטפורמות
3. מפגש עם **שער חוכמה** → חידה חינוכית
4. פתרון → השער נפתח **+ כוח** (מגן/מגנט/כוכב)
5. דגל סיום → פרס לבוש לדמות → חזרה לרכז
6. עולם 5: קרב בוס שבו כל מכה = חידה

## 4. עקומת קושי
- עולמות נפתחים ברצף (1→5)
- בתוך עולם: שערים 1–3 מעלים את סוג האתגר
- **Adaptive:** `skill` 0.7–1.15 משפיע על מהירות אויבים; רמת קושי בפינת ההורים משפיעה על מספר אפשרויות, חיים וסף רמזים

## 5. פרסים ומוטיבציה
| שכבה | פרס |
|------|-----|
| מיקרו | יהלום +50, קומבו x2/x3 |
| שער | +300 וכוח |
| עולם | פריט לבוש (5 פריטים = תלבושת מלאה) |
| מאקרו | ניצחון סופי + קונפטי + שיא |

## 6. דמות ואמנות
- לני: SVG וקטורי מונפש (נשימה, מצמוץ, שיער מתנועע) — 6 מצבי אנימציה
- 5 ערכות נושא ניאון; רקע parallax; חלקיקים; screen shake
- PWA: אייקון, manifest, offline

## 7. סאונד
- 100% סינתזה (WebAudio) — אין קבצי מדיה
- מוזיקה מז'ורית/מינורית לפי מצב לילה
- TTS עברי לכל הוראה ועידוד

## 8. נגישות
- RTL מלא, ניקוד בטקסטים לילדים
- aria-labels, role=status, prefers-reduced-motion
- כפתורי מגע גדולים; שליטה מלאה במקלדת

## 9. מדדי הצלחה (KPIs פנימיים)
- השלמת עולם ראשון > 70% מהמשתמשים
- זמן ממוצע לחידה ראשונה < 60 שניות
- 0 קריסות (CI ירוק תמיד)
