# 🧒 ערכת פלייטסט — LENY (#1, #27)

הכלים כבר קיימים במשחק; המסמך מסביר איך מריצים מפגש מחקר עם ילדים.

## מה המשחק כבר מקליט (אוטומטית, מקומית)
- `stats.levels[רמה]` — מספר משחקים, מיתות, כשלי חידות, שניות, ניצחונות
- `stats.domains[תחום]` — ניסיונות/הצלחות/אחוז הצלחה
- `stats.sessions` / `playSec` — מפגשים וזמן מצטבר

## הפקת דוח
פינת ההורים (החזקה על ⚙️) → "⬇️ הורדת דוח פלייטסט" → קובץ `leny-playtest-report.json`.

## פרוטוקול מפגש (3–5 ילדים)
1. הסכמה מההורה (המשחק אוסף אפס נתונים לרשת; הדוח נשאר במכשיר).
2. תנו לילד לשחק לבד 10–15 דק׳. אל תעזרו; רשמו היכן עצר/התבלבל.
3. אחרי המפגש: הורידו את הדוח + מלאו טבלת תצפית:
   | ילד/גיל | עצר איפה? | התבלבל בחידה? | חיוך/תסכול | הערה |
4. השוו דוח JSON מול התצפית — אתרו פערים (המקום שבו הילד עצר אבל הדוח לא מראה = חסר מדידה).

## קריטריוני הצלחה לסגירת #1/#27
- ≥80% מסיימים עולם 1 לבד
- ≥40% חוזרים למחרת
- אין נקודת תסכול שבה >50% מהילדים עוצרים

כשהקריטריונים נמדדים בפועל עם ילדים — סוגרים את #1 ו-#27.
